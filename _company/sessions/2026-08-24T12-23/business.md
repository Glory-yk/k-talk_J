# 📊 가격 번들 옵션 & 경쟁사 ROI 분석 리포트

**작성일**: 2026-08-24
**작성자**: 현빈 (머니메이커)
**상태**: **진행중** — 아키의 트렌드 데이터 반영 후 최종 결정 필요

## 1. 현재 상황 (Situation)
- **수익화 목표**: PayPal Live 연동 완료 ($4.99 / $9.99 및 $24.99 가격대 설정)
- **장애물**: `CLIENT_ID` 및 `CLIENT_SECRET` 미입증으로 실시간 매출 데이터 수집 불가.
- **대응**: 전략적 가설 수립 → 번들 옵션 기획 → 아키의 트렌드 분석 반영

## 2. 번들 옵션 전략 (Option Comparison)
### 📦 옵션 A: 스탠다드 (월간 정기결제 중심)
- **패키지**: K-Talk AI ($9.99/월) + WorkAbroad AI ($24.99/월) 통합 멤버십
- **가격**: $34.99/월 → **$29.99/월 (15% 할인)**
- **장점**: 이탈율 감소 (LTV 향상), 단가 상승
- **예상 매출 증가**: 1 인당 LTV 약 +$180

### 📦 옵션 B: 트라이얼 번들 (초기 유입 최적화)
- **패키지**: $4.99 패스 x 2 개 (K-Talk + WorkAbroad)
- **가격**: $4.99 + $4.99 = $9.98 → **$8.99 (10% 할인)**
- **장점**: 첫 구매 장벽 낮춤, 두 제품 경험 유도
- **예상 전환율 향상**: A/B 테스트 시 2~5%p 상승 가능

### 📦 옵션 C: 로열티 (연간 결제)
- **패키지**: $9.99/월 → **$107.88/년 ($8.99/월당가)**
- **장점**: 현금 흐름 안정화, 충성도 높은 고객 확보
- **예상 ROI**: 유지비 절감 및 마케팅 비용 효율화

## 3. 경쟁사 분석 (Competitor Analysis)
*(아키의 트렌드 수집 데이터를 기반으로 추정)*
| 경쟁사 | 주요 특징 | 예상 가격대 | 우리 전략 포인트 |
| :--- | :--- | :--- | :--- |
| **ELSA Speak** | 발음 진단 전문 | $6.99/mo | **한국어 특화 + 일본인 타겟** 차별화 ($4.99 진입 장벽) |
| **Cambly** | 실시간 튜터링 | $10~25/mo | **AI 기반 24/7 접속** (즉시성 강조), 워홀 영어 실전성 |
| **TalkPal** | 언어 학습 앱 | $6.99/mo | **롤플레잉 시나리오** 심화 콘텐츠 제공 |

## 4. 실행 계획 (Action Plan)
1.  **코다리에게**: 결제 테스트 환경 구축 (`sandbox` 모드로 API 키 placeholder 처리 가능하도록 스크립트 수정).
2.  **클레어에게**: 번들 옵션을 활용한 마케팅 카피라이팅 및 랜딩페이지 콘텐츠 생성 지시.
3.  **현빈**: 최종 가격 결정 (A/B 테스트 시나리오 설계) 후 결제 시스템에 반영.

**결론**: **옵션 A(통합 멤버십)** 와 **옵션 B(트라이얼 번들)** 를 병행하여 유입과 이탈 관리 모두 잡습니다.
