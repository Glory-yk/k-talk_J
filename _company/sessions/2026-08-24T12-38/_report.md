# 💰 PayPal API 키 설정 가이드

## 📌 목표
PayPal Live 환경에서 실제로 결제를 받을 수 있도록 Client ID 와 Secret 을 입력하여 파이프라인 가동하기.

## ⚠️ 현재 상태
- `paypal_revenue.json` 파일에 자격 증명이 없음 → 매출 분석 실행 불가
- `setup_paypal_env.py` 환경 설정 스크립트 생성됨 (코다리가 수정 필요)

## 🛠️ 실행 계획

### 1. API 키 발급 (PayPal Developer Dashboard)
```bash
# URL: https://developer.paypal.com/dashboard/applications
# Apps & Credentials → 본인 앱 → Client ID + Secret 복사
```

### 2. 설정 파일 업데이트
설정 파일 위치: `/Users/glory/Desktop/coding/Makemoney-connectAI/_company/_agents/business/tools/paypal_revenue.json`

예시 내용 (비밀번호는 실제 값으로 교체):
```json
{
  "client_id": "YOUR_CLIENT_ID_HERE",
  "client_secret": "YOUR_SECRET_HERE",
  "mode": "live"
}
```

### 3. 테스트 환경 준비 (코다리 담당)
- 샌드모드/라이브 모드 선택 가능 여부 확인
- `setup_paypal_env.py` 스크립트 실행하여 자동 설정 가이드 제공

## 📞 요청 사항
**대표님**: 아래 URL 에서 본인 PayPal 앱의 Client ID 와 Secret 을 복사해 주세요.  
→ [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications)

**코다리**: 테스트 환경 설정 스크립트 (`setup_paypal_env.py`) 를 확인하고, 샌드모드/라이브 모드 전환 로직을 구현하세요.
