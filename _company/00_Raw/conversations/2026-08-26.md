# 💰 PayPal API 인증 및 매출 데이터 수집 가이드 (현빈 작성)

## 🚨 중요: 수익화 전략의 핵심은 '진짜 돈'입니다.
사장님, 지금 우리의 K-Talk AI 와 WorkAbroad AI 가 이미 결제 시스템을 갖추고 있지만, **실제 트래픽이 들어왔을 때 그 돈을 얼마나 벌었는지**를 증명할 데이터가 없습니다.

데이터가 없으면 다음 일을 못 합니다:
1.  **가격 전략 수립**: $4.99 vs $9.99 번들 가격대별 수요 분석 불가
2.  **마케팅 효율 검증**: 광고비 대비 매출 (ROAS) 계산 불가
3.  **자동화 마케팅 활성화**: 유료 구독자가 생겼을 때 알림 발송 불가

이 파일을 보고 다음 작업을 따라 해주세요.

---

## 🛠️ 단계 1: PayPal 개발자 계정 및 API 키 발급 (2 분 소요)

1.  **[PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications)** 접속
2.  **Apps & Credentials** 메뉴 클릭
3.  **"Live" 환경 확인**: 지금 우리가 팔리는 것은 실제 돈이 오가는 '라이브' 모드입니다. 샌드보드는 제외합니다.
4.  **App 생성 및 복사**: 
    -   "Create App" 버튼 누르고 앱 이름 입력 (예: `Makemoney-Live-Sales`)
    -   생성 후 화면에 나타나는 **Client ID** 와 **Secret** 을 그대로 복사하세요.
    -   🔒 **주의**: 이 키는 절대 타인에게 공개하지 마세요. 우리의 현금 흐름입니다.

---


---

## 📈 단계 3: 데이터 수집 자동화 시작

키가 입력되면 `setup_env.py` 가 자동으로 어제와 오늘의 매출 데이터를 가져옵니다.

-   **예상 데이터**: 
    -   K-Talk AI (일본인 타깃): 약 $50 ~$150/일 (예상)
    -   WorkAbroad AI (한국인 타깃): 약 $30 ~$80/일 (예상)
