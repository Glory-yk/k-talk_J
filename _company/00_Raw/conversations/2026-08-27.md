# 💰 PayPal API 키 발급 및 .env 설정 가이드 (v2)

## 🎯 목표
- PayPal Developer Dashboard 에서 **Live Mode**용 Client ID 및 Secret 발급

## 🔐 단계별 설정

### 1️⃣ PayPal Developer Dashboard 접속
- URL: [https://developer.paypal.com/dashboard/applications](https://developer.paypal.com/dashboard/applications)
- **로그인**: 본인이 소유한 PayPal 비즈니스 계정 (Live Mode 사용 가능) 또는 샌드박스 환경 (개발 테스트용)

### 2️⃣ 앱 생성 및 자격 증명 발급
1.  **"Apps & Credentials"** 메뉴 클릭
2.  **"Create App"** 버튼 누르기
3.  **App Name**: `Makemoney-ConnectAI` 또는 고유한 이름 입력
4.  **Live Mode** 선택 (실제 매출 데이터 수집용)
5.  앱 생성 후 **"Show Credentials"** 클릭
6.  **Client ID** 및 **Secret** 복사

### 3️⃣ `.env` 파일 생성 및 키 값 입력
프로젝트 폴더 내 `.env` 파일 생성:
```bash
# PayPal Live Mode 자격 증명 (실제 결제 연동용)
PAYPAL_CLIENT_ID=여기에_복사한_Client_ID_넣기
PAYPAL_SECRET=여기에_복사한_Secret_넣기

# WorkAbroad AI 제품 ID (제품 목록 관리용)
WORKABROAD_PRODUCT_ID=products/work-abroad-monthly-unlimited
KTALK_PRODUCT_ID=products/k-talk-weekly-pass

# 결제 수수료 설정 (각 제품별 비율)
FEE_PERCENTAGE=0.03
```

### 4️⃣ 보안 주의사항
- `.env` 파일은 `.gitignore` 에 포함하여 버전 관리 시스템에서 제외
- 키 값은 절대 타인에게 공유하지 않기

## 1 단계: PayPal Developer Dashboard 에서 앱 생성
1.  **주소 방문**: https://developer.paypal.com/dashboard/applications
2.  **로그인**: 본인의 PayPal 계정으로 로그인하세요. (개인 계정 또는 비즈니스 계정 모두 가능하나, Live 모드는 필수)
3.  **앱 생성**
    *   `Apps & Credentials` 메뉴 클릭
    *   `Create App` 버튼 누름
    *   앱 이름: `Makemoney-KTalkAI` 또는 `Makemoney-WorkAbroadAI` (프로젝트별 분리 권장)
    *   비즈니스 유형 선택: `Individual` 또는 `Business`

## 2 단계: Live 환경 활성화 및 키 추출 (중요!)
**⚠️ 주의:** 테스트 모드 (Sandbox) 가 아니라 **Live 모드를 사용**해야 실제 돈이 들어옵니다.

1.  생성된 앱 클릭 -> `Live` 탭 확인.
2.  왼쪽 메뉴에서 `Credentials` 선택.
3.  `Live mode` 스위치가 켜져 있는지 확인 (`On`).
4.  **Client ID** 복사: 상단 텍스트 박스 내용 전체 복사.
5.  **Generate Secret** 클릭 -> **Client Secret** 복사 (이 키를 절대 남에게 주지 마세요).
