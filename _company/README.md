## ⚙️ 로컬 Ollama 실행 가이드

1. **Ollama 설치 및 백그라운드 실행**:
   ```bash
   ollama run llama3.2
   # 또는 gemma2, qwen2.5-coder 등
   ```
2. **Connect AI 사이드바**:
   - 사이드바 설정에서 Ollama 서버 주소(`http://127.0.0.1:11434`) 확인
   - 원하는 모델(예: `llama3.2`, `gemma2:9b`, `qwen2.5-coder:7b`) 선택 후 대화 시작
