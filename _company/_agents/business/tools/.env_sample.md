# 💰 PayPal API 키 입력 가이드 (.env 파일)

## 🚀 목적
K-Talk AI 와 WorkAbroad AI 의 **PayPal Live Mode** 연동을 위해 `CLIENT_ID` 와 `CLIENT_SECRET`을 안전하게 저장합니다.

## ⚠️ 중요: 보안 및 설정 사항
- 이 파일은 `.gitignore` 에 등록되어 있습니다. 절대 git 에 커밋하지 마세요!
- **Live Mode** (실제 결제) 를 사용하려면 반드시 Live 환경의 API 키를 입력하세요. (Sandbox 는 테스트용)

## 📝 입력 방법
`.env_sample.md` 내용을 복사해서 `.env` 파일로 저장한 후, 아래 변수만 채워넣으세요.

```bash
# 1. PayPal Developer Dashboard (https://developer.paypal.com/dashboard/applications) 에서 발급받은 Live Mode 키를 여기에 붙여넣습니다.
CLIENT_ID=여기에_ClientID_붙여넣기
CLIENT_SECRET=여기에_ClientSecret_붙여넣기

# 2. 앱 이름 (선택 사항, 결제 승인 시 표시됨)
APP_NAME="Makemoney AI Lab"

# 3. 환경 모드 (Live = 실제 결제, Sandbox = 테스트)
ENV_MODE="Live"
```

## 🔑 발급 단계별 가이드
1. [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications) 접속
2. **Apps & Credentials** 메뉴 클릭
3. **Create App** 버튼 누르고 앱 생성 (App Name: `K-Talk AI`, `WorkAbroad AI`)
4. **Live Mode** 선택 후 `Get Client ID` 및 `Secret` 복사
5. 위 가이드 내용을 따라 `.env` 파일 생성 및 입력 완료
