# 📊 PayPal 매출 분석 템플릿 (재활용용)

**사용 목적:** 코다리가 API 키 입력 완료 후, `paypal_revenue.py` 가 수집한 데이터를 기반으로 자동으로 생성될 산출물 구조. 현빈이 미리 준비해 둔 분석 프레임워크.

## 1. 데이터 수집 결과
- **총 매출**: `$0.00` (초기)
- **거래 건수**: `0 건`
- **평균 주문 가치 (AOV)**: `$0.00`
- **원화 환율**: `(실시간 적용)`

### A. 7 일 무료/테스트 패스 ($4.99)
- **타겟**: 일본인 한국어 학습자 (초보자)
- **전환율 예측**: `(데이터 수집 시 반영)`
- **수익 기여도**: `$(총 매출 * 비율)`

### B. 월간 무제한 구독 ($9.99 / $24.99)
- **타겟**: 한국인 워홀러 (실전 영어 필요자)
- **전환율 예측**: `(데이터 수집 시 반영)`
- **수익 기여도**: `$(총 매출 * 비율)`

## 3. 전환율 최적화 제안
- **현재 문제점**: (데이터 부족 시 "먼저 데이터가 필요합니다")
- **개선안**: 
  - 바이럴 대본 (클레어) 으로 트래픽 증가 유도
  - 결제 페이지 UI 테스트 (코다리)

## 4. ROI 분석
- **마케팅 비용 대비 수익**: `$(ROI)`
- **고객 획득 비용 (CAC)**: `(트래픽 * 단가)`
- **LTV (Lifetime Value)**: `(구독 기간 * 월 요금)`
