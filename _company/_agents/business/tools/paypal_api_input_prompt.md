**대표님, 첫 달러를 잡기 위해 PayPal 설정을 완료하겠습니다!**  
현재 매출 분석 파이프라인이 준비되어 있는데, 마지막 단계인 **API 자격 증명 (Client ID & Secret)**만 필요합니다. 아래 버튼을 클릭하여 자격 증명을 입력하세요.

---

## 📥 PayPal API 키 입력 방법

### ✅ 1. PayPal Developer Dashboard 접속
- [https://developer.paypal.com/dashboard/applications](https://developer.paypal.com/dashboard/applications) 로 이동합니다.
- **Apps & Credentials** → 본인 앱 선택 → **Live Mode**로 전환 (실제 결제 허용).
- **Generate Client ID** → **Secret** 복사.

### ✅ 2. 입력 버튼 클릭 및 값 붙여넣기
아래 버튼을 클릭하여 값을 입력하세요.

```json
{
  "client_id": "당신의 Client_ID",
  "secret": "당신의 Secret"
}
```

### ✅ 3. 자동화 파이프라인 가동
입력 완료 후 즉시 매출 분석 스크립트가 실행됩니다.  
첫 매출 데이터가 들어오면 바로 알림을 드릴게요! 🚀
