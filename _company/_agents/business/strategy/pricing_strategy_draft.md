# 💰 Makemoney AI Lab - 가격 번들 최적화 전략 (Draft)

## 1. 분석 배경 및 목표
- **목표**: K-Talk AI 와 WorkAbroad AI 의 수익성 극대화
- **현재 상황**: PayPal Live 연동 완료 상태 (결제 로직 검증됨), 실제 매출 데이터 확보 전 (API 키 입력 대기 중)
- **전략 방향**: 신규 고객 전환율(CAC) 최적화 vs 기존 고객 LTV(월간 무제한) 증대

## 2. 가격 전략 시나리오 (A/B 테스트 설계안)

### 📦 번들 A: 입문자 타겟 (초저가 장벽 진입)
- **상품**: K-Talk AI 7 일 패스
- **가격**: $4.99 / $3,000 KRW
- **전략**: 낮고 확실한 진입 장벽으로 구독 전환 유도 -> 월간 무제한으로 업셀링 (Cross-sell)
- **추정 전환율**: 15% ~ 25%
- **예상 월 매출 (LTV)**: $4.99 * 30 회 * 60% (월 전환율) = 약 $900

### 📦 번들 B: 중장기 타겟 (안정적 현금 흐름)
- **상품**: WorkAbroad AI 월간 무제한
- **가격**: $24.99 / $35,000 KRW
- **전략**: 영어 실력 향상에 집중하려는 유저 대상 프리미엄 제공 -> 워홀/취업 성공 사례 연동
- **추정 전환율**: 8% ~ 12%
- **예상 월 매출 (LTV)**: $24.99 * 30 회 = 약 $750

### 📦 번들 C: 하이브리드 전략 (가장 추천)
- **상품**: K-Talk AI 7 일 패스 + WorkAbroad AI 7 일 패스 (捆绑 판매)
- **가격**: $12.98 (단독 합산 $9.98 대비 $3 할인)
- **전략**: 이중 타겟(일본인 한국 학습, 한국인 영어 학습) 모두 공략 -> 고객 생태계 확장
- **추정 전환율**: 10% ~ 15%
- **예상 월 매출 (LTV)**: ($4.99 * $24.99) * 30 회 = 약 $600

## 3. 실행 계획 및 우선순위

| 단계 | 작업 내용 | 담당 에이전트 | 예상 효과 |
| :--- | :--- | :--- | :--- |
| **1** | API 키 입력 완료 및 데이터 파이프라인 가동 | 코다리 (엔지니어) | 실제 매출 데이터 확보 |
| **2** | 랜딩 페이지 가격 버튼 A/B 테스트 설계 | 현빈 (수익화) | 전환율 5% 이상 상승 |
| **3** | 이메일/앱 내 푸시 알림 자동화 (업셀링) | 코다리 + 클레어 | 월간 구독 전환율 20% 증대 |
| **4** | 번들 C(捆绑 판매) 랜딩 페이지 제작 및 배포 | 현빈 | 신규 고객 확장률 1.5 배 상승 |

## 4. 의사결정 요청 사항 (CEO)
- **[우선순위 1]**: API 키 입력 가이드 (`api_key_guide.md`) 배포 후 실제 매출 데이터 확보 시점에 대한 결정 필요.
- **[우선순위 2]**: 번들 A(입문자) 와 번들 B(중장기) 중 우선 배포를 위한 승인 요청.
