## 📋 작업 내용
1. **데이터 모델 확장**:
   - `User Profile` 테이블에 `level`, `current_xp`, `total_learning_time` 필드 추가.
   - 학습 기록 (`Session Log`) 에 `xp_gained` 필드 포함.
2. **비즈니스 로직 구현**:
   - 발음 정확도 (K-Talk) / 문법 점수 (WorkAbroad) 가 10% 이상 오르면 XP 획득 로직 적용.
   - 레벨업 조건: 현재 레벨의 필요 XP 달성 시 자동 레벨업.
3. **프론트엔드 UI**:
   - 프로필 페이지에 레벨 바 및 배지 아이콘 표시.
   - "레벨 업 완료" 알림 팝업 (Push Notification 연동) 구현.

## 💡 주의사항
- 기존 API 엔드포인트 변경 없이 데이터 필드만 추가하되, 기존 앱 호환성 유지.
