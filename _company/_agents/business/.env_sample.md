```bash
cd "/Users/glory/Desktop/coding/Makemoney-connectAI/_company/_agents/business/tools"
python3 setup_env.py
```

## 🔑 입력해야 할 값들

### PayPal Live Mode (실제 결제용)
- `CLIENT_ID`: PayPal Developer Dashboard 에서 발급한 Client ID
- `CLIENT_SECRET`: 동일한 앱에서 발급한 Secret Key
- `PAYPAL_MODE`: `"live"` (실제 거래용)

### 테스트 모드 (개발용)
- `PAYPAL_MODE`: `"sandbox"` (테스트용)
