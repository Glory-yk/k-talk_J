# 🚀 사용자 유지율 (Retention) 증대 기능 기획서: "AI 튜터 레벨업 시스템"

## 1. 전략적 배경 (Why Now?)
- **문제점**: 언어 학습 앱의 가장 큰 병목은 **3 회차 이후 이탈**입니다. K-Talk AI 와 WorkAbroad AI 모두 초기 구매 후 꾸준한 사용률이 떨어지는 경향이 예상됩니다.
- **해결책**: 단순 반복 학습이 아닌 **"성장감"과 "공유 가능한 성취"**를 제공하는 게이미피케이션 (Gamification) 요소 추가.
- **기대 효과**: 월간 구독 유지율 10%~15% 상향 기대 및 유료 전환율 증가.

## 2. 핵심 기능 제안: "AI 튜터 레벨업 & 달성 시스템"
### 🎯 기능 설명
사용자의 총 학습 시간, 정정된 문장 수, 특정 주제를 마스터한 횟수에 따라 **레벨 (L1 ~ L5)**을 부여하고, 각 레벨마다 **특수 배지**를 획득할 수 있게 합니다.

### 💰 수익화 연동 전략 (Monetization)
- **유료 기능**: "초과 학습" 시 경험치 배율이 2 배로 증가하거나 (Premium), 전용 스킨/배지를 구매할 수 있는 기능을 내장.
- **가격 전략**: 레벨업 시스템이 있는 버전은 현재 월간 무제한 요금제보다 **+15% 프리미엄**을 책정하되, 첫 달 무료 체험 기간 제공하여 전환율 테스트.

### 🛠️ 기술적 구현 (Developer Scope)
- **데이터 포인트**: 기존 학습 로그 (Learning Log) 에 `level`, `xp`, `badges` 필드 추가.
- **로직 변경**: AI 응답 후 사용자의 정답률/발음 점수에 따라 XP 계산 로직 적용.
- **저장소**: Firebase 또는 기존 DB에 레벨 데이터 연동.

## 3. 실행 일정 및 리소스 요구
- **개발자 (코다리)**: 백엔드 데이터 모델 수정 + 프론트엔드 배지 UI 컴포넌트 구현.
- **마케터 (클레어)**: 레벨업 달성 시 공유 가능한 이미지 템플릿 생성.

## 4. 예상 ROI
- **유입**: 레벨 시스템은 신규 사용자들에게 "오늘 하루도 해보자"는 심리를 자극하여 DAU (일일활발사용자) 증가.
- **수익**: 유지율 상승으로 인한 Churn Rate 감소 → LTV (고객생애가치) 증대.
