### 💰 현빈 (머니메이커) — 가격 번들 전략 가설 메모 (v1.0)
**작성일:** 2026-08-25 | **상태:** API 데이터 부재 대비 (가설 기반)

---

#### 📊 1. 현재 문제 및 기회
- **문제:** 아직 실제 매출 데이터가 없으므로 A/B 테스트를 통한 최적 가격은 모른다.
- **기회:** 가격 번들 옵션을 도입하여 전환율 (Conversion Rate) 을 인위적으로 높일 수 있다.

#### 💡 2. 제안 전략: '학습 시간' 번들링
단순 결제 금액이 아닌, **'가치 인식'**을 심어주어 충성도를 높입니다.

**안 A: $9.99 기본패키지 + $2.99 추가 학습 (Learning Pack)**
- **컨셉:** "첫 7 일은 무료로 끝내시고, 더 많은 학습 시간으로 3 번 더 결제하세요."
- **예상 효과:** 첫 결제 장벽 낮춤 → 리텐션 증가

**안 B: $14.99 무제한패키지 (Bundle)**
- **컨셉:** "기본 기능 + 프리미엄 발음 분석 + unlimited 예제 문장"
- **타겟:** 직장인, 학습자 (WorkAbroad AI, K-Talk AI 모두 공통 적용)

#### 📈 3. 예상 ROI 계산 (가상 데이터 기반)
- **기존 월간 매출 ($9.99 기준):** $500 (예시)
- **번들 전략 적용 시 전환율 (+15% 가정):** $575 → $600 목표
- **추가 수익원:** 추가 학습 시간 판매 ($2.99, 월 3 회 구매 가정) → +$8.97/사용자

**결론:** 번들 옵션을 준비해두고, 실제 매출이 오를 때마다 전략을 수정할 수 있도록 유연하게 잡겠습니다.
